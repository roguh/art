# Galaga: An Exact Copy of Hit Copyrighted 1981 Videogame

This is a CLI videogame that attempts to replicate Galaga (1981).

Movement controls:

- Left and right arrow keys to move
- Spacebar to fire

For now, all you can do is fly your ship through a starfield and fire missiles.
